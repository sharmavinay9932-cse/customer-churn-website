## 📌 About the Project

ChurnAI is a customer churn prediction project that I built to understand how a machine learning model can be taken from a dataset and turned into a working web application.

The application takes customer information such as tenure, contract type, monthly charges, payment method, internet services, and other service details.

It then uses a trained machine learning model to estimate the probability that the customer will leave the service.

The application also includes an AI-based retention strategy feature that can suggest possible actions for customers who are at higher risk of churn.

---

## 🎯 What the Project Does

The main goal of the project is simple:

> **Predict which customers are likely to churn and identify their risk level.**

The application:

- Takes customer information as input
- Performs data preprocessing
- Applies feature engineering
- Selects important features
- Uses Logistic Regression for prediction
- Calculates churn probability
- Assigns a risk level
- Displays the result through a web interface
- Can generate AI-based retention suggestions
